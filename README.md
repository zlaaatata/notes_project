
# Приложение для ведения заметок

Учебный проект по дисциплине «Технологии программирования».

## Описание

Клиент-серверное веб-приложение для создания, просмотра, редактирования и удаления заметок.

## Технологии

- Python
- Flask
- SQLite
- HTML, CSS
- Jinja2

## Возможности

- Просмотр всех заметок
- Создание заметки
- Редактирование заметки
- Удаление заметки
- Сохранение данных в SQL-базе

## Запуск

1. Установить Flask:

   python -m pip install flask

2. Запустить сервер:

   python app.py

3. Открыть в браузере:

   http://127.0.0.1:5000

## Структура проекта

- app.py — сервер, обработчики запросов и работа с базой данных.
- templates/ — HTML-шаблоны страниц.
- static/style.css — оформление сайта.
- notes.db — база данных SQLite, создаётся автоматически.
